# 🧪 Projeto de Teste

Este repositório foi criado para fins de teste, experimentação e aprendizado.  
Aqui você pode validar fluxos de trabalho, testar comandos Git, explorar funcionalidades do GitHub ou experimentar novas ideias sem comprometer projetos reais.

## 📁 Estrutura do Projeto

- `src/` — Código-fonte e scripts de experimentação
- `notebooks/` — Notebooks para testes e prototipagem
- `data/` — Dados de exemplo para validação
- `docs/` — Documentação e referências
- `README.md` — Informações do projeto

## 🚀 Como usar

1. Clone o repositório.
2. Explore os notebooks e scripts.
3. Teste comandos Git e funcionalidades do GitHub.

## 🛠️ Tecnologias

- Python
- Jupyter Notebook
- Git & GitHub
